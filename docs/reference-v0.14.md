## 项目配置与原作未知项

源码沿用项目条件：指挥中心2级、6份水、6份共享food库存，成功后各扣4并给10金币。现有指挥中心开局为1级，所以界面写“升级指挥中心”，不能把升级2级声称为截图证明的规则。水目标亦来自项目原有配置。历史图中的10份仅是历史跨渠道线索，没有把首餐5份改为10，也没有将风暴改为10。

首餐需要累计真实领取5份食物并交付；风暴储备按当前库存显示，消耗可令备妥目标回退；过关后显示已完成的条件记录，当前实际库存仍在资源栏。该计数方式沿用本项目，不声称已验证原作库存/累计或回退规则。共享food继续兼容农田和旧厨房，此版本不拆分资源或迁移存档。

分目标“前往”只打开生鱼片生产页、指挥中心管理页或净水器页；缺设施引导建造，不自动排产、消费、升级、结算或领奖。备齐仍须主动迎接风暴，任务奖励仍由原有领取入口发放。
