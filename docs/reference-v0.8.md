新增独立`seafoodKitchen`类型，与旧`kitchen`海上厨房分开；没有给新厨房附加旧式自动热食产出。**建造费用22木材+10废料沿用项目旧厨房配置，尚未证实原作费用**；原14步后开放也仍是项目衔接。原12项后追加“建造海产厨房”和“收藏家想吃一条烤鱼”两个目标，前者奖励未知，完成时不编造奖励；后者成本与奖励有上述画面支持。两个目标排在既有12项之后是项目顺序，不声称是原作连续主线。

画面在2级切鱼厂中显示可生产鱼肠线，**不足以证明原作最低解锁等级就是2级**。本项目暂以2级作为衔接门槛，UI可由工坊返回切鱼厂管理进行升级；无需先做完旧14项任务。切鱼厂的原有生鱼片自动生产保持，二者共用鲜鱼库存。鱼肠线在入队时一次支付，后续自动生产只可消耗余量；原料不足时引导去钓鱼。

`production.version` 升至2。v1的已付订单保留ID、原料、产物、时长、剩余时间与状态；不是用新配方重新算旧订单。旧14项与12项后续任务的领取记录保持。鱼肠线或烤鱼领取后即使队列为空，也保留版本2标记，让旧v0.7客户端拒绝覆盖它不了解的新库存；静态回滚不代表存档可向下兼容。

以上是同一时点同时存在的任务；经验是该面板标示奖励，未从该帧推定额外物品奖励。本轮没有将这张任务板直接接成网页的串行目标，也没有借此宣称原版后续任务已全部补齐。

以上采样证明“出现过”，不拼接为已核实的全部连续主线。海产厨房采用上述明示的项目建造费用，烤鱼配方与收藏家交付按实录采用；广播站、潜水船坞仍缺完整条件，没有做成空占位。海藻汁还缺海藻、玻璃的获取链，暂只保留证据。旧12项项目建设任务保留，不更名冒充这些原作任务。

[10:54](https://www.bilibili.com/video/BV1Vt9MByEP8/?t=654)还可确认原作生鱼片是6鲜鱼、90秒、库存50。本轮未悄悄改变旧首餐和自动生产规则；迁移到原版手动队列仍需单独处理旧已存产物、居民消耗和前14步平衡。

长绳与木板目前仍未找到可读的原料和时间证据，保留v0.7明确标注的项目数值。官方图可见切鱼厂的生鱼片、鱼肠线、鱼籽、鱼胶、鱼油、鱼皮、鱼骨；海产厨房的烤鱼、海藻汁、刺身拼盘、薯条、南瓜派、鱼饼汉堡。产品存在不能用来反推数量或耗时。
