## 证据使用规则

- **D：目标渠道明确**。官方抖音小游戏公告或可见客户端的抖音实机。公告证明活动/入口存在，不自动证明全部截图来自同一客户端版本。
- **P：厂商发布、跨渠道参考**。广州益玩的小米攻略，其中多数明确注明“玩家投稿，不代表官方立场”；不能把这些攻略直接当成抖音当前精确规则。
- **S：其他官方商店版本**。App Store 更新日志证明该版本内容存在，不证明抖音同时开放，也不替代逐关配置或实际操作证据。
- **U：玩家/第三方实际截图**。可帮助还原可见界面，客户端渠道、时间与完整规则待核验。
- 宣传插画、投放短剧、商店海报不作为实机 UI / 操作流程证据。数字是历史攻略描述时，保留日期与待核验标识。

**“完整复刻”的验收至少同时覆盖：可见画面、真实交互、状态变化、数值配置、解锁顺序、失败/恢复、存档、多日/赛季节奏。** 仅放入口、填关卡数字、播放随机战斗、用本地假玩家代替多人联盟，均应标“模拟/部分实现”，不能标已完整复刻。

## 阵型与战斗视觉：本轮可直接采用的事实

1. P6 的实机布阵页显示 **5 名英雄**，不能把背景格子数当英雄上限。“攻速增强”图有六个黄色位置其中一空；“闪避增强”图则是不同站位几何。原作阵法不是统一的六格棋盘。具体坐标仅在对应阵法/截图成立。
2. 布阵页为深蓝纸面/舰船战术图、黄色位置框、整个人物立绘与等级，顶部英雄人数/总战力，底部阵营光环、海兽卡、阵法缩略图。U1 卡册则为四列头像卡，带品质色、等级、星和碎片进度。
3. D1 战前页是满屏手绘风浪与锈船甲板；P6 阶段页底部有关卡横条、红色开战、阵容入口。不要把实验室 BOSS 背景说成所有主线背景。
4. U2 活战斗能核实的只有：两侧头像/总血条、中央倒计时、个体血条、黄色伤害字、投射物/护盾/闪电等表现。它是第三方实验室 BOSS 截图，索敌与技能公式仍未知。
5. 在抖音实机未对证之前，新增可见战斗可以交付为“英雄—布阵—战斗—闯关—挂机的可玩闭环”；精确阵法、技能数值与关卡配置应保留“待校准/模拟”状态，不写“完全一致”。

## 版本漂移：不能用 3000 关作为完整上限

[App Store 当前页面][S1] 本轮显示版本 **1.1.8**；历史日志包含 1.0.9 新增 2701–3000、1.1.3 的 S6 3501–3900，以及 1.1.5 的 S7 3901–4300。此处只是可核实的版本内容线索，**不是抖音当前最大关数承诺**。同页还出现芯片/核芯、博物馆、联盟职级、自由组盟、赛季商店等模块。

已发现应专门回归的规则变化：旧联盟攻略的固定分盟与新版自由组盟；旧城战“出发不能回”与新版零耐久召回；旧远征失败/死亡继承与新版失败恢复；战斗跳过有时间门槛也有特权更新。只能按目标抖音版本分别取证，不能拼出一个跨年代的“原版规则”。
