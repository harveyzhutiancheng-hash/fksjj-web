## 渲染与生命周期

战斗演出只读取领域事件；胜负由个体血量、攻击、护甲、护盾、技能、控制与召唤物结算，不由总战力比较决定。领域时间从演出实际时间提交，切页与关闭会保存并释放战斗视图，营地渲染在全屏英雄界面暂停。

机器狗/机器人实际生成、重复 seek 不重复生成、跳转后血量与 `hpAfter` 一致、历史 seek 不重放事件回调、重复跳过不重复完成已由独立视图测试验证。独立视图另测 844×184 容器与连续创建销毁 40 次，全部战斗 context 主动释放，另一个保留 context 未丢失，0 warning / 0 pageerror；独立测试不替代集成页面回归。

后台暂停演出并停止自动闯关，领奖计时器同时检查可见性；隐藏时先提交时间并保存。代码分支审查不等于真实手机后台切换验收。复玩关卡不发第二份首通奖励，界面显示首通已领。
