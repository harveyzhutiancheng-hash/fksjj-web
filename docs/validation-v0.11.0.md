## 数据与时间边界

医院前存档从零通过公开领域动作生成，包含三趟实际有界潜水，每趟12玻璃、20海藻、16废金属；36玻璃足够日用品20和后续海藻汁10。专用支线存档通过公开净水器领取与烤鱼10+9批量加工生成，没有手工注入产量、经验或库存。历史v0.9/v0.10存档文件未覆写。

这些领域存档用`tick`推进时间，并通过公开`collect('coin')`准备部分资金；它们证明链路可达，不证明自然金币节奏接近原版。对应记录为`earned-fixture-provenance.json`、`earned-side-provenance.json`与`fixture-provenance.json`。

浏览器日用品/海藻汁加工、厨房升级和订单烤鱼采用仅修改`savedAt`的受控离线时间戳，不是自然等待20分钟/5分钟。船坞按实际墙钟等待验证。

原作事实和项目兼容规则见[来源说明](reference-v0.11.md)。主视频渠道仍未独立确认；完整金币节奏、24份需求所需订单池、其他建筑施工时间和完整材料费尚有缺口。
