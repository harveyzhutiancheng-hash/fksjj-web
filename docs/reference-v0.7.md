本项目把一级强化的10次操作计为总计500金币；达到10%后，需要两艘拾荒船再升级拾荒等级。二级倍率400%、容量200由升级预览的当前值与增量相加得到，本次没有录到成功升级后二级窗口的独立确认。二级后续强化费用、概率上限、三级成长与全部船只门槛尚未核实，本项目在二级停止扩展。

原作画面还显示皮肤可改变拾荒速度与单次容量，但本轮没有实现或推导完整皮肤数值。当前项目的强化、等级升级立即影响本趟**后续拾取**；已得货物不重算、已出现的资源堆不重新生成。这是明确的项目交互选择，实录没有验证升级发生在航程中时的全部追溯规则。

## 队列、库存与存档解释

- 每座工厂各自先进先出，最多3个批次，一批1至10件；不同工厂并行。同批数量累加加工时间。**3批和批量10是项目配置**，不是对实录可见队列槽位或其解锁方式的精确还原。
- 入队一次扣齐整批原料，同时保存当时的输入、输出和时长。完成的批次留在工厂，手动领取后才进入营地背包；领取过的批次不能再次发奖。
- 画面“库存0/50”本身有实录证据，但以下占用方式是项目解释：每座工厂、每项配方最多预留50件成品，包含排队、加工和待领批次；领取后释放预留，营地背包没有这个50件限制。原作的库存占用时机及背包限制未完整核实。
- 关闭面板不暂停加工。离线最多推进2小时，重新载入不重复扣原料或再次完成同一批次；离线完成也不自动入库。货网航行仍在隐藏页面或暂停时停止移动。这些恢复规则是项目实现。
- 保留外层存档key `fkssj-save-v1` 与版本1；新增 `production.version=1`、`continuation.version=1`，拾荒子版本升至2。旧档缺字段补空队列和零成品，不补发历史货物；未来版本或损坏的已付费批次会锁定自动保存并保留原始存档。

## 独立的12项后续建设任务

下面的顺序、目标、交付消耗和奖励均为**项目配置**。原片返航后的[10:50 / 650秒](https://www.bilibili.com/video/BV1Vt9MByEP8/?t=650)可见建造海产厨房0/1，[11:40 / 700秒](https://www.bilibili.com/video/BV1Vt9MByEP8/?t=700)可见建造广播站0/1；本轮没有取得全部任务的连续清晰记录，因此没有改写原14步任务历史来伪装原版顺序。

| 顺序 | 本项目目标 |
| --- | --- |
| 1 | 完成一次手动拾荒返航 |
| 2 | 拥有材料厂 |
| 3 | 累计领取2布匹 |
| 4 | 累计领取1长绳 |
| 5 | 拥有建材厂 |
| 6 | 累计领取2木板 |
| 7 | 拥有服装作坊 |
| 8 | 累计领取1救生衣 |
| 9 | 明示交付1救生衣、4淡水、4食物 |
| 10 | 完成至少1次拾荒概率强化 |
| 11 | 拥有2艘拾荒船 |
| 12 | 明示交付3木板、2布匹、2长绳、1救生衣 |

任务从原14步完成后开始，按序领取、每项仅发一次奖励。旧档已有航程、建筑和累计产出可计入目标，认进度不会重新发放旧货物。交付任务在按钮前显示成本，领取时原子扣除该成本；整链只要求一次50金币强化，不要求把可选的二级拾荒养成做满。

布匹改用实录20碎布后，整链中的布匹加工共需6匹、120碎布；再加3根长绳与2件救生衣，按本项目配方共需146碎布。这是加工总耗，未扣除任务发放的原料或已有库存。它属于多次拾荒的目标，不能把原来的少量原料fixture当作新配方验证。每次新航程均有可再收集的碎布，返航后可继续出海；任务没有要求一次航程装齐全部原料，也不要求二级拾荒才能完成。已经付费的旧生产批次仍沿用其保存的材料与时长，不因新证据追改订单或补扣原料。

仍待核实：长绳、木板及工厂其余产品的完整配方、原作任务全序列、全部队列槽位和自动生产解锁、二级后续成长、异常拾荒失败的实际扣返比例。本轮可玩闭环不代表这些系统或抖音渠道规则已完整还原；部署与浏览器验收另看相应验证记录。
