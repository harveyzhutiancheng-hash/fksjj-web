实现及原作证据见 [公开实录对照](reference-v0.6.md)。本轮增加手动拾荒、三种独立材料、鱼群/鲨鱼、暂停恢复与返航，仍不是原作全量复刻完成。

## 规则与本地浏览器

- `npm test`：43/43通过，经营14、英雄与闯关18、拾荒11，输出 `test-results/v0.6-qa/domain.tap`。覆盖门槛、真实移动碰撞、重复拾取、货物与仓库分离、返航幂等、旧档材料补零、位置/危险/拾取标记精确恢复、离线不航行、三击失败、鱼群抢料、失败剩料一次返还、未来版本保护及指南持久化；新增100容量、部分末堆持久化与旧无容量存档默认迁移。
- `test-results/v0.6-qa/scavenging-local.json`：10项触控流程通过。使用真实CDP touch拖动摇杆采集三种材料；检查松手停止、暂停、暂离、刷新、继续同航程、返航精确入库、背包显示、重载不重复结算及新航程空货网。

- `test-results/v0.6-qa/results-regression.json`：9项旧英雄/战斗回归通过，包括旧档补偿只执行一次、升级只耗经验、单券招募、五位置交换、实际HP变化、退出/刷新续战、精确首通奖励和下一关。

新模块测试沿用 `test-results/progression-qa/ui-earned-prebattle.json`：原经营教程通过公开GameState动作推进，随后真实UI升级/抽卡/换位留下的旧档。本轮只更新首次载入时间，不改任务/英雄/钱包/物资或补丁运行时。它不是本轮从新账号按自然时长完成全部教程。上述最终流程未记录页面错误；请求失败只在具备网络监听的报告中统计，不能将未监听的危险测试写成网络失败为0。

开发过程有一次测试选择器同时匹配隐藏暂停弹窗和底部“暂离”按钮，改为明确底部按钮选择器后通过。原始记录 `test-results/v0.6-qa/first-selector-error.json`；没有为绕过测试改变游戏规则。

## 响应式与渲染

`test-results/v0.6-qa/responsive/scene-results.json`：390×844、320×568、844×390均完成真实触控移动、三材料拾取、暂停/继续和暂离；页面无横向溢出，画布铺满，按钮可点击。同一报告记录27 draw calls / 5250 triangles，60次更新geometry数量稳定23；暂停停止动画，销毁释放上下文与根节点。这是固定场景采样，不是所有设备帧率承诺。Canvas降级320×568可显示并清理，见 `responsive/freeze.json`。

`responsive/full-results.json`：三尺寸均显示100已满载、绿色返航按钮，满载仍能移动，真实点击返航精确入库100。此处为**受控满载fixture**：沿用已得经营/英雄存档，通过GameState移动到实际物资堆收满；只在准备阶段移除危险物，未直接写货物/拾取数。来源见 `responsive/full-visual-provenance.json`，不等于在原危险环境连续自然收满100。第一次旧文本断言把“100（已满载）”误判为“100”，只修正测试断言后通过，留档 `responsive/full-results-initial-text-assertion.json`。

## 存档与边界

外层 `fkssj-save-v1` 和 `version:1` 不变；`progression.version:2`不变；新增 `scavenging.version:1`。旧档补塑料/碎布为0，保留原经营和英雄进度。当前航程保存位置、已拾物体、货物、鱼群/鲨鱼位置、时间、冷却、受击次数及失败/返航状态。普通营地tick与离线生产不推进航行。碰撞/拾取/返航立即保存，普通移动随原自动保存和暂离/页面生命周期保存。

静态上一版目录保留不等于可无损降级存档：0.5代码不了解新增材料/拾荒字段，会丢弃它们。实际回滚前需保留0.6浏览器原始存档并准备相应迁移策略。

100容量来自录像中初期等级满载提示；地图、速度、拾取数量和鱼群扣料比例是项目配置；失败后保留剩余货物也是明确的保护性配置，未证明原作返还方式。规则测试通过不证明数值与抖音当前版本完全一致。

浏览器为隔离Chrome的触控/手机尺寸模拟，**未完成物理手机验收**。离线冻结由领域规则、实际暂离/刷新证明；页面隐藏/失焦暂停接线另经只读审核，未扩大成真实手机后台验收。没有运行前端构建、没有Git提交或推送。
