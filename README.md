# 疯狂水世界 · 海上家园、手动拾荒与远海救援 · v0.14.0

目标是逐步复刻**抖音小游戏渠道的《疯狂水世界》完整游戏**。当前源码实现了 14 项经营教程、摇杆手动拾荒及强化、60秒海底潜水、六类设施加工、九项配方、20项故事目标、14项后续建设任务与5项生产支线，以及英雄招募、培养、基础阵容、可见战斗、40 关救援和挂机闭环，尚未完成原作全部系统，也没有还原原版完整数值。当前运行形式仍是手机浏览器网页，未接入抖音小游戏 SDK 或完成平台发布。

当前源码版本为 **0.14.0**，包括账号身份校验与冻结保护、风暴分目标进度、加工状态和手机布局。源码版本、CI 通过与测试站实际部署是不同状态；站点运行版本应以公开 `release.json` 和发布运行结果为准。

发布通过 GitHub Actions 的手动 `workflow_dispatch` 发起：固定提交、测试、白名单打包、签名上传、服务端验收与原子切换。默认只暂存，不在每次 push 时上线。首次服务端配置和启用须按[接入说明](docs/github-release-setup.md)完成；仓库工作流不能代替服务器权限、真实 API 验收或发布结果核验。

[原作证据与待确认规则](docs/reference-v0.14.md)、[验证范围](docs/validation-v0.14.0.md)。历史 0.13 的[来源说明](docs/reference-v0.13.md)、[验证记录](docs/validation-v0.13.0.md)和[发布回执](deploy/receipt-v0.13.0-2026-10-20.json)仅用于追溯，不作为当前版本测试结论。

画面采用程序化 3D 与 SVG：灰钢板平台、剥漆绿墙、彩色窄桥、方形黄色棚顶和钓鱼椅，远处为蓝海中的沉没楼宇。英雄有独立头像与战斗模型，战场显示攻击、技能、血条、召唤物、护盾和控制反馈。新增战前页为单艘蓝绿剥漆船舱与锈甲板，显示真实出战英雄和等级，底部提供横向关卡轨道、红色开战、阵容及挂机入口。模型与素材由本项目实现，不代表原作美术、镜头或资源已完全还原。

## 本地运行

使用 Node.js 24 和锁文件中的依赖：

```sh
npm ci --ignore-scripts
npm run dev
```

电脑打开 `http://localhost:4173`。手机与电脑连接同一局域网，打开终端打印的 `Network` 地址。开发服务默认监听 `0.0.0.0:4173`，可用 `PORT` 修改端口。

项目使用原生 ES Modules，无需构建，Three.js 从本地 `node_modules` 加载。

## 经营教程

1. 从 3 × 3 浮台、指挥中心和 1 位居民开始，木材 8、废料 6、淡水 3、金币 10，鲜鱼和食物为 0。首次有 3 段阿海对话；看完或跳过都会保存已看状态，刷新不重播。
2. 跟随可见指引点击漂流木、油桶、补给箱拾荒。累计打捞 15 份木材并领取任务奖励后，建造钓鱼椅；点击椅子的操作菜单进入钓鱼。
3. 甩竿后等待咬钩，再按提示约 4 次快速连点收线，进度满后才结算 3–5 条鱼；结算后有 2.5 秒整理冷却。自动钓鱼遵循相同流程；退出或切后台会停止自动并取消未完成的一轮，返回不自行恢复。
4. 累计获得 15 条鱼，建切鱼厂。消耗鲜鱼制作并领取至少 5 份生鱼片，再把库存中的 5 份交给阿海，获得 60 领袖 XP、升至 Lv.2，完成首餐需求后才能领取对应主线奖励。
5. 建净水器、领取淡水、扩建 2 格、建拾荒船，在海域救回 2 位伙伴，再建睡铺和农田。指挥中心升至 2 级、储备至少 6 水和 6 食物后主动迎接风暴，成功消耗各 4 份补给。
6. 风暴后建归航信标并领取最后奖励，完成 14 项教程；之后可继续经营和自由建造。**渡过第一次风暴后**，英雄和远海闯关入口已经开放，无须等到最后一项领奖。

生产设施可领取产物、派工和升级；工人数受居民总数限制，无工人时仍缓慢生产。钓鱼椅的被动生产与手动收鱼独立计算，鱼篓产物需领取才入仓。拖动海面移动镜头，双指、滚轮或缩放按钮调整大小，定位按钮返回营地。

居民订单按顺序解锁，每份只扣料、发奖一次；领袖每 60 XP 升一级，另有金币及少量木材、废料奖励：

| 订单 | 解锁条件 | 交付 | 领袖经验 |
| --- | --- | --- | --- |
| 先让大家吃上饭 | 累计从设施领取至少 5 份生鱼片 | 5 食物 | 60 XP |
| 再备一壶干净的水 | 首单完成、累计领取至少 6 份淡水 | 4 水、2 食物 | 80 XP |
| 给新伙伴留一份 | 前两单完成、首次海上救援完成 | 6 食物、4 水 | 100 XP |
| 防臭大师的餐点 | 前三单、收藏家烤鱼交付完成且有海产厨房 | 1 烤鱼、1 淡水 | 40 XP、120金币（实录686/688秒） |

首餐交付前，饥渴值可以下降，但居民不自动消耗库存水和食物，确保首餐物资可交付；交付后恢复正常生理消耗。

## 手动拾荒

建好拾荒船后，点击 **海域 → 出海拾荒**，或从拾荒船设施菜单进入。首次显示操作与危险说明，之后可直接继续已有航程。

- 拖动摇杆或海面驾驶白色小筏，接近漂浮物后收集；键盘方向键与 WASD 也可操作。木材、塑料、碎布分别计数，先留在货网里，返航才进入营地背包。
- 初始货网容量100；最后一堆只取剩余空间，满载显示绿色返航按钮，仍可驾驶。容量来自公开实录的初期等级，不代表原作所有升级等级。
- 鱼群会夺取已收物资，鲨鱼累计撞击三次结束本次航程。失败后允许把剩余货物带回是本项目保护性配置，尚未证明原作的失败返还方式。
- 支持暂停、暂离、重载续航、结算后再次出海。位置、拾取标记、货物和危险物状态随存档恢复；离线不航行、不自动拾取，返航奖励只结算一次。

拾荒界面右下角“升级”打开三项属性面板：初级每次50金币，加倍概率增加1%，累计10%；两艘拾荒船满足后可升到2级，容量200、加倍倍率400%。二级值由实录预览增量推导，未声称全部等级已还原。强化立即影响本趟之后的拾取，已得货物不重算；随机进度随档保存。

三种材料支持独立保存和背包显示。拾荒地图、速度、物资堆、鱼群扣料比例与危险间隔为项目配置，自动拾荒和更高等级仍待补齐。原有即时救人功能独立保留。

## 英雄、闯关与挂机

英雄名册含米娅、一龙、雷教授、大嘴山姆、兰博、巫师老侃、李忠诚、机修萝莉。技能定位参考发行方发布的玩家攻略：李忠诚召唤机器狗，机修萝莉召唤机器人；召唤物有独立生命与攻击、能承伤，最多存在 15 秒；巫师老侃提供攻速、暴击增益及护盾；雷教授释放五道雷电，米娅提供群体控制。

- **招募**：首次单次免费，已有抽数不再赠送；其余使用游戏内招募券，支持单次、十次并共享 50 次保底，获得传说后重置。重复英雄转为同名碎片。米娅通过第 40 关救援获得，不在招募池；没有真实充值。
- **培养**：升级只消耗英雄经验；升星消耗同名碎片、精华和培养金币，最高 50 级、6 星。培养钱包与营地经营资源独立，英雄经验也与领袖 XP 区分。
- **布阵**：默认五个位置，采用公开实机可见的左三右二构图，可换位、移除或一键上阵。站位影响目标选择，召唤物不占额外阵容格。
- **战斗**：按确定性单位攻击、目标、伤害、召唤、增益和控制事件逐步演出，不用单次战力比较代替战斗。支持 1× / 2×，战斗进行满 10 秒可跳到预先算出的结果；离开页面暂停演出并保留进度。切后台通过 `suspend()` 提交播放时间、停止自动闯关并取消待执行的自动领奖，返回不自行开启自动。
- **奖励**：40 关是本项目配置的首段关卡，逐关解锁；胜利后手动领取，支持领取后进入下一关及可关闭的自动闯关。失败可调整培养、阵容后重试。首通奖励只结算一次，第 40 关首次领奖救出米娅；重复通关不再展示或发放首通奖。
- **挂机**：第 1 关首通领奖后开始，按最高已通关关数提高每分钟收益，最多积累 2 小时，需要手动领取。0 关期间收益和容量均不累积；领取保留不足整数的余额，刷新、重复点击不重复发奖。

招募概率、保底重置策略、技能数值、冷却、召唤寿命、培养经济和 40 关敌人配置均为**本项目配置**，不是原作精确数值。账号与云存档已实现，并具有身份隔离、CAS 冲突、CSRF/Origin 与 Secure Cookie 保护；真实浏览器跨上下文恢复仍需独立验收。联盟、海兽、跨服、完整装备和运营活动等系统尚未实现；基础阵容也不等于原作全部阵法与战斗规则。

## 静态部署

静态文件和账号 API 分开部署。API 不随静态归档分发；发布器只接受固定仓库、分支、提交与清单绑定，不执行上传归档中的程序。账号 API 的身份隔离、存档 CAS、CSRF/Origin、Secure Cookie 和重启持久性验收必须在切换前通过。

正常发布使用[GitHub 接入与运行说明](docs/github-release-setup.md)。下列打包命令供本地核验，它本身不会上传或切换版本。

以下命令仅准备发布目录，不会构建或上传；输出目录必须尚不存在且父目录已存在：

```sh
node deploy/package-static.mjs
# 或指定输出目录
node deploy/package-static.mjs --output /tmp/fkssj-release-0.14.0
```

白名单现有 **34 个静态文件**，包括账号管理/界面/样式、页面锁及风暴界面模块；经营、英雄、战斗模块及 Three 依赖继续保留。静态目录不包含Python API，账号后端须通过既有独立服务流程更新。脚本另写 `release.json`，记录版本、各文件 SHA256/字节数和不含清单自身的总字节数：

```text

scavenging-state.js
scavenging-view.js
scavenging-ui.js
scavenging-ui.css
production-state.js
production-ui.js

assets/favicon.svg

node_modules/three/build/three.core.js
node_modules/three/LICENSE
```

Three 的两个模块必须保持上述相对路径，不上传整个 `node_modules`、开发服务、测试结果或其他工程文件。发布目录位于 `/srv/fkssj/releases/<release-id>`，核对清单后原子切换 `/srv/fkssj/current`，保留前一目录以便回滚。

配置源文件：`deploy/nginx.conf` 为独立 8080 静态服务；`deploy/nginx-domain-http.conf` 为首次签发前 HTTP 校验，签发后使用 `deploy/nginx-domain-https.conf`，两份域名配置不同时启用。`deploy/fkssj-cert-renew.service` / `.timer` 提供续期检查；历史记录确认 timer enabled/active、检查执行成功，但尚未证明进入续期窗口后实际换证成功。

无内容指纹的资源保持 `Cache-Control: no-cache`；JS 返回正确模块 MIME 与 `nosniff`，缺失模块返回 404，不能回退 HTML。子路径部署需保留目录结构，并将不带尾斜杠的入口跳转到带斜杠目录。`bootstrap.js` 提供模块加载失败重试。
